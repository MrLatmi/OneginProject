# Onegin — сортировка строк текстового файла

## Использование

```bash
g++ .\Onegin2.cpp
./a.exe
```

При запуске программа спросит имя выходного файла:

```
Write file's name for writing sorted text or 0 to use standard file name 'newOnegin.txt'
```

- Введите `0`, чтобы использовать имя по умолчанию — `newOnegin.txt`.
- Либо введите своё имя файла — результат будет записан в него.
